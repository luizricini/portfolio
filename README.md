# ricini.dev

Personal portfolio of Luiz Ricini — full-stack engineer shipping AI products end to end.

Next.js 15 (App Router, static export) deployed on Vercel. English at `/`, Brazilian Portuguese at `/pt/`.

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # static site in out/
```

- Content (both languages, projects, roles, real commit logs): `src/content.ts`
- Page: `src/components/Page.tsx`; git-graph rows: `src/components/Graph.tsx`
- Styles and tokens: `src/app/globals.css`
- CV served from `public/cv/Luiz-Ricini-CV.pdf`
